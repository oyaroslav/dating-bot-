# Пользовательское соглашение

**Telegram-бот «Ковчег» (@Kovcheg7bot)**
Дата последней редакции: 19 мая 2026 года.

## 1. Назначение Бота

Telegram-бот «Ковчег» (далее — «Бот») — это сервис, помогающий христианам познакомиться друг с другом. Бот не является брачным агентством и не несёт ответственности за результаты знакомств.

## 2. Использование

Использовать Бот могут совершеннолетние пользователи (старше 18 лет), являющиеся христианами.

Регистрируясь в Боте, пользователь подтверждает, что:

- Достиг возраста 18 лет
- Не находится в действующем браке
- Использует свои настоящие данные и фотографии
- Принимает Политику обработки персональных данных

## 3. Правила поведения

Запрещается:

- Размещать оскорбительные, экстремистские, порнографические или иные противоправные материалы
- Выдавать себя за другое лицо
- Использовать Бот для рассылки спама, рекламы, мошеннических предложений
- Размещать чужие фотографии без разрешения
- Преследовать, угрожать или оскорблять других пользователей

Нарушение правил влечёт блокировку анкеты без возможности восстановления.

## 4. Модерация

Любой пользователь может пожаловаться на анкету через кнопку «🚩 Жалоба». Администрация Бота рассматривает жалобы и принимает меры на своё усмотрение.

## 5. Ответственность

Администрация Бота:

- Не проверяет подлинность данных, указанных пользователями
- Не несёт ответственности за действия пользователей вне Бота (в личной переписке, при личных встречах и т.п.)
- Не гарантирует бесперебойную работу сервиса
- Вправе в одностороннем порядке изменять функционал и правила работы Бота

## 6. Завершение использования

Пользователь может в любой момент удалить свои данные через команду `/forget` в Боте.
