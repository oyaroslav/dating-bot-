# 🤖 Telegram Dating Bot — пошаговая инструкция

Этот бот умеет:
- Принимать анкеты пользователей (имя, возраст, пол, кого ищет, город, описание, фото)
- Показывать анкеты других людей с кнопками ❤️ / ❌
- Когда два человека лайкают друг друга — отправлять обоим уведомление с контактом

---

## Часть 1. Получаем токен бота (5 минут)

1. Открой Telegram и найди бота **@BotFather**.
2. Нажми **Start**, затем напиши `/newbot`.
3. Придумай имя бота (как будет видно в чате), например: `Мой бот знакомств`.
4. Придумай username — должен оканчиваться на `bot`. Например: `my_dating_demo_bot`.
5. BotFather пришлёт сообщение со строкой вида:
   ```
   1234567890:AAEhBP0av28abcdefghijklmnopqr1234567
   ```
   Это **токен**. Сохрани его — нужен дальше.

## Часть 3. Запуск на сервере (рекомендую)

Бот должен работать **24/7**. На своём компьютере неудобно — выключил ноут и бот умер. Поэтому берём дешёвый сервер (VPS).

### Шаг 1. Покупаем VPS

Подойдёт любой провайдер с Ubuntu. Самые простые и дешёвые:

- **Timeweb Cloud** (российский, оплата картой РФ) — от ~150 ₽/мес
- **Aeza** (принимает РФ-карты и крипту) — от ~200 ₽/мес
- **Hetzner** (Германия, нужна карта Visa/Mastercard зарубежного банка) — от ~5€/мес
- **DigitalOcean** (международный) — от 4$/мес

Для бота хватит самой дешёвой конфигурации: **1 CPU, 1 ГБ RAM, Ubuntu 22.04 или 24.04**.

После оплаты тебе пришлют:
- IP-адрес сервера (например, `185.123.45.67`)
- Логин (обычно `root`)
- Пароль

### Шаг 2. Подключаемся к серверу

**На Windows:** скачай программу [PuTTY](https://www.putty.org/) или используй встроенный PowerShell.
**На macOS / Linux:** открой Терминал.

Подключаемся командой:
```bash
ssh root@185.123.45.67
```
(подставь свой IP). Введи пароль (символы при вводе не отображаются — это нормально).

### Шаг 3. Устанавливаем нужное ПО

Скопируй и вставь в терминал по очереди:

```bash
apt update && apt upgrade -y
apt install -y python3 python3-pip python3-venv git nano
```

### Шаг 4. Загружаем код бота

Самый простой способ — закачать файлы вручную. Создай папку и файлы:

```bash
mkdir ~/dating_bot && cd ~/dating_bot
nano bot.py
```

Откроется редактор. Вставь содержимое файла `bot.py`. Чтобы сохранить:
- `Ctrl+O`, затем `Enter` — сохранить
- `Ctrl+X` — выйти

Повтори для остальных файлов:
```bash
nano database.py        # вставь код database.py
nano requirements.txt   # вставь содержимое requirements.txt
```

### Шаг 5. Создаём файл с токеном

```bash
nano .env
```
Внутри одну строку:
```
BOT_TOKEN=1234567890:AAEhBP0av28abcdefghijklmnopqr1234567
```
(подставь свой токен от BotFather). Сохрани (`Ctrl+O`, `Enter`, `Ctrl+X`).

### Шаг 6. Устанавливаем зависимости

```bash
cd ~/dating_bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Подожди минуту — установятся библиотеки.

### Шаг 7. Запускаем бота

```bash
python3 bot.py
```

В терминале появится:
```
INFO:root:База данных готова. Запускаем бота…
INFO:aiogram.dispatcher:Start polling
```

🎉 Бот работает! Открой Telegram, найди своего бота по username и напиши `/start`.

## Часть 4. Делаем так, чтобы бот не умирал

Сейчас бот работает только пока открыт терминал. Закроешь — выключится. Чтобы он работал постоянно, настроим **systemd** (стандартный механизм Linux).

Останови бота: `Ctrl+C`.

Создай служебный файл:
```bash
nano /etc/systemd/system/datingbot.service
```

Вставь:
```ini
[Unit]
Description=Telegram Dating Bot
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/dating_bot
ExecStart=/root/dating_bot/venv/bin/python3 /root/dating_bot/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Сохрани (`Ctrl+O`, `Enter`, `Ctrl+X`). Включаем:

```bash
systemctl daemon-reload
systemctl enable datingbot
systemctl start datingbot
```

Проверка статуса:
```bash
systemctl status datingbot
```
Должно быть зелёное `active (running)`.

Теперь даже если ты выключишь компьютер или сервер перезагрузится — бот сам поднимется.

### Полезные команды:
```bash
systemctl restart datingbot   # перезапустить (после изменений в коде)
systemctl stop datingbot      # остановить
systemctl status datingbot    # посмотреть, работает ли
journalctl -u datingbot -f    # смотреть логи в реальном времени
```

## Часть 5. Тест с двумя людьми

Чтобы проверить матч, нужно **минимум 2 пользователя**:

1. Найди бота со своего основного аккаунта, заполни анкету.
2. Попроси друга/родственника тоже найти бота и заполнить анкету.
3. У одного нажми ❤️ на анкету другого.
4. У второго нажми ❤️ на первого — оба получат сообщение с контактом.

Чтобы лайки сработали как «матч», у обоих в анкете должны совпадать предпочтения по полу.

## Часть 6. Альтернатива: запуск на своём компьютере (для проверки)

Если просто хочешь поиграться, не покупая сервер:

**Windows:**
1. Установи [Python 3.11+](https://www.python.org/downloads/) — при установке поставь галочку **Add Python to PATH**.
2. Открой папку `dating_bot` через проводник, нажми правой кнопкой → «Открыть в терминале».
3. Выполни:
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. Создай файл `.env` с токеном (как в шаге 5).
5. Запусти: `python bot.py`

Бот будет работать, пока открыто окно терминала.

**macOS / Linux:** то же самое, только команды:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 bot.py
```

## Если что-то не работает

| Проблема | Решение |
|----------|---------|
| `BOT_TOKEN не найден` | Проверь, что файл называется именно `.env` (с точкой) и лежит рядом с `bot.py` |
| Бот не отвечает | Проверь токен, посмотри логи: `journalctl -u datingbot -f` |
| `ModuleNotFoundError: aiogram` | Активируй venv: `source venv/bin/activate` и снова `pip install -r requirements.txt` |
| Анкеты не показываются | Нужно минимум 2 заполненные анкеты с совместимыми полами/предпочтениями |

Удачи! 🚀
